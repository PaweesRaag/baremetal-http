# Baremetal HTTP

A fully functional HTTP server written from scratch in **x86-64 Assembly**.

No frameworks. No abstractions. Just **Linux syscalls, sockets, registers, memory, and a lot of stubbornness.**

Built to understand what actually happens underneath the networking stack.

> **Because if C can do it, why not Assembly?**

## Highlights

- x86-64 Assembly
- Linux socket programming
- Client-server communication
- Multi-client handling
- Manual register & memory management
- Built in progression where webserver11.s is the final

Built from scratch. No AI.
